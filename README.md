# React Frontend Study Guide

A project-led guide to learning modern React, frontend architecture patterns, and application data flow.

## Guide

Read **[REACT_FRONTEND_STUDY_GUIDE.md](REACT_FRONTEND_STUDY_GUIDE.md)**.

It covers:

- React's rendering and one-way data-flow model
- State ownership, reducers, context, hooks, Effects, and refs
- Controlled components, composition, adapters, state machines, and feature architecture
- API requests, mutations, caching, optimistic updates, and race conditions
- TypeScript, routing, forms, accessibility, testing, and performance
- An eight-week study roadmap with deliberate-failure exercises
- Three progressive portfolio projects
- Debugging and production-readiness checklists

The guide is designed around a **30% study / 70% implementation** learning ratio and uses official React, TypeScript, Vite, and Testing Library documentation.
